# Retail Sales Performance & Insights Dashboard

## Project Overview
This project analyzes retail sales data using MySQL and Microsoft Power BI. It helps identify sales trends, profitability, product performance, customer behavior, and discount patterns.

## Project Objectives
- Analyze total sales, profit, and quantity sold.
- Identify top-performing products and categories.
- Compare sales across states and cities.
- Analyze customer segments and payment methods.
- Understand discount patterns.
- Support data-driven business decisions.

## Tools Used
- MySQL – SQL queries and data analysis
- Microsoft Power BI – Interactive dashboards and visualizations

## Project Files
- `Retail sales project sql zaid.sql` – SQL queries used for analysis.
- `Retail Sales Performance & Insights Dashboard.pbix` – Power BI dashboard.
